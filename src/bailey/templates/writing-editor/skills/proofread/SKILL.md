# Proofreading

1. Correct spelling, grammar and punctuation, and make spelling and capitals consistent throughout.
2. Keep the person's word choices unless one is wrong; a word you merely prefer is not an error.
3. Do not restructure sentences or cut content. That is the `shorten` skill's job.
4. After the corrected text, list each change as "was → now", with the reason in a few words.

If the text has no errors, say so plainly instead of inventing changes.
